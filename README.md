# Re:Member

Личный дневник для Android: день, сон, траты, заметки, задачи, тренировки и здоровье в одном приложении.

Делается для себя, без Google Play и своих серверов. Все данные хранятся на телефоне в зашифрованной базе. Интернет нужен только странице «Сеть», записи никуда не отправляются.

## Возможности

### Сегодня

- **День:** оценка дня, теги и текст с фото. Оценка закрывается замком от случайного изменения.
- **Сон:** время сна с подсказкой по использованию телефона и запись снов.
- **Траты:** расходы и доходы за день, свои категории с порядком и значками, подсказки комментариев из прошлых записей выбранной категории.
- **Серия дней:** огонёк, который меняет цвет с ростом серии.
- **Выбор дня:** календарь в виде сетки или списка, настраиваемое время смены дня.

### Записи

- **Заметки:** папки, теги, закрепление, редактор с форматированием и фото. Отдельные заметки можно защитить PIN-кодом или отпечатком.
- **Лента:** все записи дней и раздел «В этот день».
- **Поиск** по записям.
- **Галерея** всех фото из дней и заметок.
- **Редактор текста:** Markdown, настраиваемые красная строка и отступ между абзацами, отмена автозамены.

### Планы и время

- **Задачи** со сроками и подзадачами.
- **Календарь** событий и дней рождения.
- **Напоминания:** отчёт за день, сон, события и тихие часы.
- **Будильники:** повторы, отсрочка, плавная громкость, своя мелодия. Срабатывают после перезагрузки ещё до первой разблокировки, а пропущенный из-за выключенного телефона звонок прозвучит при включении.
- **Усиленный будильник** выключается только игрой в слова и звонит снова, если снова уснуть.
- **Таймер и секундомер** с уведомлениями и временем в строке состояния.

### Зал и здоровье

- **Тренировки:** упражнения и подходы четырёх видов (вес и повторы, повторы, время, скорость и время), вес тела, заметка, поиск по упражнению, импорт из JSON.
- **Подсказки подходов:** результат с прошлого раза и сколько тренировок он держится.
- **График упражнения** с выбором срока и подходами выбранного дня.
- **Шаблоны:** готовые списки упражнений, которые добавляются в тренировку одним нажатием и идут друг за другом.
- **Здоровье:** шаги и активность из Health Connect, цели и уведомление об их выполнении.

### Статистика и остальное

- **Статистика** с heatmap-ами по категориям.
- **Финансы:** доходы и расходы за месяц и год.
- **Сеть:** скорость интернета, проверка белых списков и внешние IPv4 и IPv6.
- **Игры:** «Пять букв» и Ра[скобки].

### Настройки

- **Безопасность:** PIN-код, отпечаток, автоблокировка. Вход в приложение отключается отдельно от защиты заметок.
- **Данные:** резервная копия в файле под паролем и восстановление, занятое место, показатели памяти, процессора, диска и батареи, отзыв разрешений.
- **Персонализация:** темы, цвет акцента, шрифты (системный, Inter, Nunito, Medeo), режим левши, направление свайпа, вибрация.
- **Страницы:** состав вкладок и плиток, отключение ненужных разделов.
- **Профиль:** имя, язык (русский и английский), валюта, начало недели.

## Стек

- Kotlin, Jetpack Compose (Material 3), Navigation 3

- Health Connect, BiometricPrompt

## Сборка и запуск

Нужны Android Studio (с ней идут JDK и Android SDK) и телефон с Android 13 или новее, на котором включена отладка по USB или Wi-Fi.

Команды запускаются из корня проекта. В PowerShell вместо `./gradlew` пишите `.\gradlew.bat`.

Отладочная сборка (из Android Studio это кнопка **Run**):

```bash
./gradlew installDebug
```

Релизная сборка для каждодневного использования. Она заметно плавнее отладочной, данные на телефоне сохраняются:

```bash
./gradlew installRelease
```

Релиз подписан отладочным ключом, чтобы ставить его напрямую. Для публикации понадобится свой ключ.

Только собрать APK, он появится в `app/build/outputs/apk/release/`:

```bash
./gradlew assembleRelease
```

Юнит-тесты:

```bash
./gradlew testDebugUnitTest
```

Тесты на телефоне (приложение и его данные не удаляются, в отличие от `connectedAndroidTest`):

```bash
./gradlew installDebug installDebugAndroidTest
adb shell am instrument -w dev.chaik.remember.test/androidx.test.runner.AndroidJUnitRunner
```
