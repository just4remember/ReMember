# Re:Member

Личный дневник для Android: день, сон, траты, заметки, задачи, тренировки, здоровье и места в одном приложении.

Делается для себя, без Google Play. Все данные хранятся на телефоне в зашифрованной базе. Интернет нужен только отдельным функциям: замеру сети, карте, игре Ра[скобки] и отправке резервной копии на свой сервер. Записи дневника никуда не отправляются, кроме зашифрованной копии на сервер, который вы указали сами.

## Возможности

### Сегодня

- **День:** оценка дня, теги и текст с фото. Оценка закрывается замком от случайного изменения.
- **Сон:** время сна с подсказкой по использованию телефона за весь день (подходит и тем, кто спит днём), несколько вариантов на выбор, запись снов.
- **Траты:** расходы и доходы за день, свои категории с порядком и значками, подсказки комментариев из прошлых записей выбранной категории.
- **Серия дней:** огонёк, который меняет цвет с ростом серии.
- **Выбор дня:** календарь в виде сетки или списка, свайп по дате, настраиваемое время смены дня.

### Записи

- **Заметки:** папки, теги, закрепление, ручной порядок, редактор с форматированием и фото. Отдельные заметки можно защитить PIN-кодом или отпечатком.
- **Редактор текста:** Markdown, ссылки, горизонтальная черта, чек-листы, настраиваемые красная строка и отступ между абзацами, порядок кнопок панели, отмена автозамены.
- **Поиск** по дням, снам, заметкам, задачам, событиям, тратам, тренировкам и местам с отбором по периоду и тегам.
- **Галерея** всех фото из дней и заметок.

### Планы и время

- **Задачи** со сроками, приоритетами, повторами и подзадачами.
- **Календарь** событий и дней рождения.
- **Напоминания:** отчёт за день, события, задачи, утренняя сводка, Ра[скобки] и тихие часы.
- **Будильники:** повторы, отсрочка, плавная громкость, своя мелодия. Срабатывают после перезагрузки ещё до первой разблокировки, а пропущенный из-за выключенного телефона звонок прозвучит при включении.
- **Усиленный будильник** выключается только игрой в слова и звонит снова, если снова уснуть.
- **Таймер и секундомер** с уведомлениями и временем в строке состояния.

### Зал и здоровье

- **Тренировки:** упражнения и подходы нескольких видов (вес и повторы, повторы, время, вес и время, дистанция, дистанция и время, скорость и время), вес тела, заметка, встроенный секундомер для упражнений на время, поиск по упражнению, импорт из JSON с шаблоном файла.
- **Справочник упражнений** с подписями и **шаблоны** тренировок.
- **Подсказки подходов:** результат с прошлого раза и сколько тренировок он держится.
- **Здоровье:** шаги, активное время и калории из Health Connect, цели и уведомления об их выполнении, доступ к истории за всё время.

### Статистика

- **Сон, дни, траты, зал и здоровье:** графики, тепловые карты как на GitHub, сравнение будней и выходных, выбор периода (месяц, год, всё время, свой).

### Карта

- **Места** с категориями, значками и описанием.
- **Скачивание городов** для работы карты без интернета.

### Игры

- **«Пять букв»:** английское слово за 6 попыток без интернета.
- **Ра[скобки]:** ежедневная головоломка в своём интерфейсе (с разрешения автора игры), вход в аккаунт сайта raskobki.app по ссылке из письма, общий с сайтом прогресс, напоминание.

### Остальное

- **Сеть:** скорость интернета, проверка белых списков, внешние IPv4 и IPv6.
- **Виджеты:** часы со стрелками, цифровые часы и кольца здоровья с настройками цвета, шрифта, даты, серии и языка.
- **Обратная связь:** форма отзыва автору (отправка заработает вместе с сервером).

### Настройки

- **Безопасность:** PIN-код, отпечаток, автоблокировка. Вход в приложение отключается отдельно от защиты заметок.
- **Данные:** резервная копия в файле под паролем, автоматическая отправка копий на свой сервер по расписанию, восстановление, занятое место, показатели памяти, процессора, диска и батареи, отзыв разрешений.
- **Персонализация:** темы (светлая, тёмная, AMOLED, One Dark, Night Owl, Solarized Light, Tokyo Night Light), цвет акцента, шрифты (системный, Inter, Nunito, Medeo), режим левши, направление свайпа, вибрация.
- **Страницы:** состав вкладок и плиток, отключение ненужных разделов.
- **Профиль:** никнейм, язык (русский и английский), валюта, смена дня, начало недели.

### Что входит в резервную копию

Записи дней, сны, траты, заметки, задачи, события, тренировки, места, фото, будильники, все настройки, язык приложения, статистика игр и прогресс Ра[скобок].

Не входят и задаются заново: PIN-код и блокировка, вход в Ра[скобки], адрес, токен и пароль копий на сервер, скачанные карты.

## Сервер резервных копий

Копии можно отправлять на свой сервер. Он лежит рядом, в папке [`../BackupServer`](../BackupServer/README.md): Go, Docker, хранит последние 3 копии. Сервер не может прочитать копию, она зашифрована паролем на телефоне.

## Стек

- Kotlin, Jetpack Compose (Material 3), Navigation 3
- Room + SQLCipher, ключ базы в Android Keystore
- Coil (фото и SVG), MapLibre (карта)
- Health Connect, BiometricPrompt
- minSdk 33 (Android 13), targetSdk 37

## Сборка и запуск

Нужны Android Studio (с ней идут JDK и Android SDK) и телефон с Android 13 или новее, на котором включена отладка по USB или Wi-Fi.

Команды запускаются из корня проекта. В PowerShell вместо `./gradlew` пишите `.\gradlew.bat`.

Отладочная сборка (из Android Studio это кнопка **Run**):

```bash
./gradlew installDebug
```

Релизная сборка для каждодневного использования. Она заметно плавнее отладочной, данные на телефоне сохраняются:

```bash
./gradlew installRelease
```

Релиз подписан отладочным ключом, чтобы ставить его напрямую. Для публикации понадобится свой ключ.

Только собрать APK, он появится в `app/build/outputs/apk/release/`:

```bash
./gradlew assembleRelease
```

Юнит-тесты:

```bash
./gradlew testDebugUnitTest
```

Тесты на телефоне (приложение и его данные не удаляются, в отличие от `connectedAndroidTest`):

```bash
./gradlew installDebug installDebugAndroidTest
adb shell am instrument -w dev.chaik.remember.test/androidx.test.runner.AndroidJUnitRunner
```
