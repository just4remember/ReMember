Картинки шара главной кнопки «Космо» (планета, по которой тапают).

planet_1.png … planet_8.png — шар на каждом уровне планеты (1 — стартовый, 8 — последний).
Если файла для уровня нет, берётся ближайший предыдущий (сейчас 6–8 берут planet_5.png).
Если нет ни одного — шар рисуется кодом, как раньше.

Формат: квадрат, лучше 512×512, PNG с прозрачным фоном; шар — круг во весь квадрат
(от края до края). Свечение, спутники и кольцо рисуются кодом поверх и вокруг шара —
в картинку их добавлять не нужно.

Чтобы заменить — положите свой файл с тем же именем и пересоберите приложение.
